| Boundary | Description |
|----------|-------------|
| github pr to ci workflow | Untrusted commits trigger test execution and artifact generation |
| ci outputs to artifact store | Logs, traces, and coverage data are persisted outside runner runtime |
| docs process to reviewer decisions | Quality documentation freshness depends on reviewer enforcement |

|-----------|----------|-----------|-------------|-----------------|

| T-04-05 | Information Disclosure | CI artifacts | mitigate | Use Mock-only PR E2E and restrict artifacts to test diagnostics without cloud secrets |
| T-04-06 | Denial of Service | flaky smoke gate | mitigate | Bound smoke scope to 3 happy-path journeys with one retry and deterministic fixtures per D-01/D-02/D-07 |
| T-04-SC | Tampering | NuGet package installs | mitigate | Inherit blocking package legitimacy checkpoint from 04-01 before dependency install |
</threat_model>
