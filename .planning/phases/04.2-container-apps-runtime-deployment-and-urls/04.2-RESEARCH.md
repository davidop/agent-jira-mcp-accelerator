# Phase 4.2 Research: Container Apps runtime deployment and URLs

## Objective
Deliver runtime deployment and public URL validation for API, MCP, and Web services in Azure Container Apps.

## Findings

1. Runtime deployment logic is present in deploy workflow with explicit what-if and apply stages.
2. Bicep includes conditional runtime resources gated by `deployApps` and image tag parameterization.
3. Service URL validation is implemented with `az containerapp show ... ingress.fqdn` checks.
4. Bicep outputs include URL values (`agentApiUrl`, `jiraMcpServerUrl`, `webUrl`) when runtime is enabled.

## Recommended Execution Pattern

1. Build and publish images (Phase 4.1 prerequisite) with SHA tags.
2. Run runtime what-if using `deployApps=true` and `imageTag=GITHUB_SHA`.
3. Apply runtime deployment via `az deployment group create`.
4. Verify runtime FQDN and print final URLs.

## Risks and Mitigations

- Risk: Runtime deploy references missing images.
  Mitigation: Keep ACR tag gate before runtime stage.

- Risk: Ingress URL empty due to failed app provisioning.
  Mitigation: Explicit non-empty FQDN checks with fail-fast exit.

- Risk: Permissions for ACR pull not ready at app startup.
  Mitigation: Use user-assigned identity + AcrPull role assignment in Bicep dependencies.

## Verification Commands

- `az deployment group what-if --resource-group POCMVCJIRA --template-file infra/bicep/main.bicep --parameters location=westeurope name=ent-agent-accel deployApps=true imageTag=<sha>`
- `az deployment group create --resource-group POCMVCJIRA --name runtime-<id> --template-file infra/bicep/main.bicep --parameters location=westeurope name=ent-agent-accel deployApps=true imageTag=<sha>`
- `az containerapp show --name ent-agent-accel-api --resource-group POCMVCJIRA --query properties.configuration.ingress.fqdn -o tsv`
- `az containerapp show --name ent-agent-accel-mcp --resource-group POCMVCJIRA --query properties.configuration.ingress.fqdn -o tsv`
- `az containerapp show --name ent-agent-accel-web --resource-group POCMVCJIRA --query properties.configuration.ingress.fqdn -o tsv`

## Exit Condition
Phase 4.2 is complete when runtime deployment succeeds and all three service URLs are printed and non-empty.
