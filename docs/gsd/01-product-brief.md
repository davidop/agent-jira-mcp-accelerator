# Product brief

## Product

Enterprise Agent Accelerator for Jira using MCP, .NET and Azure.

## Primary user

Delivery manager, project manager, tech lead or PMO stakeholder who needs fast, reliable project insight without manually building Jira filters or dashboards.

## Core promise

Convert Jira operational data into actionable enterprise intelligence through a governed AI agent.

## Non-goals for MVP

- Replace Jira.
- Build a full PMO suite.
- Enable write actions without approval.
- Depend on real customer data.

## Demo value

- Shows practical MCP usage.
- Uses .NET as integration layer.
- Creates a commercial narrative for Azure AI Foundry and Azure AI Search.
- Opens future opportunities with Azure DevOps, GitHub, ServiceNow, Confluence and SharePoint.
