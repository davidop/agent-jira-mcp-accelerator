# Roadmap

## Phase 1 — Local MVP

- Mock Jira dataset.
- Jira.Client abstraction.
- MCP server tools.
- Agent API with deterministic demo logic.
- Blazor UI.

## Phase 2 — Jira Cloud integration

- Basic Auth with email/API token for demos.
- OAuth 2.0 for enterprise path.
- JQL query templates.
- Better status mapping.
- Pagination and rate-limit handling.

## Phase 3 — Azure AI integration

- Azure OpenAI / Foundry orchestration.
- Prompt templates.
- Tool call tracing.
- Azure AI Search for documentation.
- Document ingestion pipeline.

## Phase 4 — Production readiness

- Entra ID.
- RBAC.
- Audit trail.
- Approval workflow for write actions.
- Container Apps deployment.
- IaC and CI/CD.

## Phase 5 — Multi-system accelerator

- Azure DevOps MCP.
- GitHub MCP.
- ServiceNow MCP.
- Confluence / SharePoint knowledge.
- PMO reporting templates.
