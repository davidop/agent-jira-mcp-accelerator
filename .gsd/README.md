# GSD working layer

This folder keeps lightweight project continuity files for AI-assisted development.

Recommended loop:

1. Read `docs/gsd/01-product-brief.md`.
2. Confirm or update `docs/gsd/02-requirements.md`.
3. Pick a phase from `docs/gsd/03-roadmap.md`.
4. Create/update a phase plan.
5. Execute small tasks.
6. Verify using `docs/gsd/05-verification-checklist.md`.
7. Ship through PR.

This is inspired by the GSD workflow, but no upstream GSD code is vendored here.
